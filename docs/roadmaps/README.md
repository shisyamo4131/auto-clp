# Roadmaps

このディレクトリは、計画作業、マイルストーン順序、未解決問題、証拠に基づく進捗の正本です。確定要件の正本は `../specification.md` です。

## Progress Method

- 各ロードマップの重みは合計100点とする。
- リポジトリ、テスト、レビュー、受入証拠で完了を確認できた作業だけを加点する。
- 部分点を認めるが、独立して検証できる完了部分、獲得点、残る受入条件を記載する。
- 範囲追加時は仕様、ロードマップ、設計、ADR、運用、変更履歴を同じ変更で更新する。
- 再計算で進捗が下がる場合は旧値、新値、理由を報告・記録する。
- 進捗は異なる製品間で単純平均しない。
- 承認待ちは直ちに報告し、回答まで追跡する。
- 長期調整ではイベント通知方式を優先し、1件のレビュー可能なチェックポイントを統合してから次を開始する。
