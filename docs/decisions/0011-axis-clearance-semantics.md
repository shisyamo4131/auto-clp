# 0011 軸別固定隙間の意味と適用面

- Date: 2026-08-27
- Status: Accepted
- Refinement: ADR 0019 applies the support-contact clearance exception to single-support and support-conditions-unverified positive-area contacts.
- Related specification: Placement and Validation; Data and State
- Supersedes: None
- Refines: 0003, 0006, 0008, 0010

## Context

案件Schema `0.1.0` と入力UIは案件共通の `clearancesMm.xMm`、`yMm`、`zMm` を保持するが、一般のコンテナ境界と積荷間で、設定値が二つの表面間の必要距離か、各積荷が所有する余白かを定めていなかった。後者では積荷間の必要距離が設定値の2倍になり、配置可能数と境界判定が大きく変わる。

ADR 0006は開口幅に左右それぞれY隙間、開口高さに床例外を除く上側Z隙間を明記し、ADR 0008は床・支持接触だけをZ隙間の例外とした。これらと矛盾せず、整数mmで等値と±1mmを決定的に比較できる一般規則が必要である。

## Decision

- 各軸の固定隙間 `cAxis` は、隣接する二つの表面間に必要な実距離とする。積荷ごとのhaloではなく、積荷間で2倍にしない。距離がちょうど `cAxis` なら合格とする。
- 配置後のコンテナ境界は、負X側開口面と正X側奥壁に各 `cX`、Y両側壁に各 `cY`、天井に `cZ` を要求する。床はZ隙間の例外とする。占有範囲の条件は `xMin >= cX`、`xMax <= L - cX`、`yMin >= cY`、`yMax <= W - cY`、`zMin >= 0`、`zMax <= H - cZ` とする。
- 負X側開口面の配置後境界にも `cX` を要求する。開口断面の搬入寸法判定はADR 0006どおりX隙間を使わず、`cargoY + 2 × cY <= openingWidth` と `cargoZ + cZ <= openingHeight` を使う。
- 支持関係ではない二つの積荷は、少なくとも一つの分離軸で表面間距離がその軸の `cAxis` 以上なら隙間条件を満たす。複数軸で分離している場合、すべての分離軸が同時に設定値を満たす必要はない。
- 正体積AABB重なりは、隙間値にかかわらず不適合とする。隙間0では面・辺・角の接触を重なりとしない既存契約を維持する。
- 床または認定された支持上面との完全一致接触はZ隙間を要求しない。支持関係を構成するX・Y投影の重なりにも積荷間隙間を適用せず、100%被覆、同一高さ、支持側の段積み可否をADR 0008の支持規則で別途判定する。
- 判定の合成では、正体積重なりを先に不適合とし、完全一致する支持候補を識別して支持例外を適用した後、残る非支持ペアの軸別隙間と支持成立を評価する。各失敗理由と対象IDは失わない。

## Rationale

利用者が「X方向の隙間100 mm」と入力したとき、隣接する積荷表面間の実距離100 mmを意味する方が自然であり、各積荷に100 mmずつ加えて200 mmを要求する解釈を避けられる。開口の `2 × cY` は左右という二つの別々の表面に各隙間を要求するためで、積荷間の二重加算ではない。

少なくとも一つの分離軸で必要距離を満たす規則はAABB非重なりの一般化であり、斜めに離れた積荷を、別の投影軸が近いという理由だけで不適合にしない。床・支持接触を明示的な例外として先に識別することで、段積みと一般隙間を混同しない。

## Alternatives

- 各積荷が軸別隙間をhaloとして所有し、積荷間で合計 `2 × cAxis` を要求する: 入力値から利用者が期待する実距離が分かりにくく、積載容量を過度に減らすため不採用。
- 複数軸で分離する場合に全軸の設定値を要求する: 正体積で重ならない斜め配置を、不要に厳しい投影条件で拒否するため不採用。
- 配置後も負X側開口面だけX隙間を免除する: 開口付近だけ一般境界と異なる未表示の例外になり、配置済み積荷が入口面へ接するため不採用。

## Impact

- Users: 入力した隙間は隣接表面間の最小実距離として読める。床・支持接触は0 mm、配置後の開口面を含む他の対象面は設定値を使う。
- Data: `clearancesMm` の形、正規単位、値域を変更せず、未定義だった意味を確定する。判定結果は保存せず再計算する。
- Implementation: コンテナ境界、非支持ペアの軸別距離、支持例外を純粋関数として分離し、理由コードを集約する。
- Tests: 各軸・各面の `c-1`、`c`、`c+1`、積荷間で設定値と2倍値を区別する例、複数分離軸、隙間0、正体積重なり、床・支持接触、開口の2Y・1Zを検証する。
- Operations: 幾何判定は計画支援であり、完全な搬入経路、構造、安定性、安全性を保証しない。

## Compatibility and Migration

Schema `0.1.0` は値の形と範囲を既に定めているが、隙間を物理判定へ接続した利用者向け機能、端末保存、利用者向けJSON入出力はまだ存在しない。このため初回の意味確定としてSchema版を据え置く。現在のメモリ内案件は実装後に本規則で再判定し、保存データ移行は行わない。

既存外部データが後から判明した場合、隙間の意味を推測して再解釈しない。由来と意味を確認し、必要なら新しいSchema版と明示的な移行経路を設計する。

## Rollback

利用者向け物理判定と保存・入出力の公開前は、本ADR、仕様、データ契約、実装、テストを一括して戻せる。公開後に距離の意味または適用面を変える場合は、同じ数値を黙って再解釈せず、新しいSchema版と移行を伴う後継ADRで本ADRをSupersededにする。

## Reconsider When

積荷別または面別の隙間、緩衝材の厚さ、通路幅、作業者用空間、扉厚、荷役機器、非軸整列形状を代表ケースで扱う必要が生じた場合。
