# 0035 単一支持グループの再帰的連動移動

- Date: 2026-09-16
- Status: Accepted
- Related specification: Placement and Validation
- Refines: ADR 0012、0015、0018、0019、0020

## Context

単一の積荷に完全支持されている上段積荷がある状態で下段だけを移動すると、上段は元の座標に残り、空中配置として不適合になる。利用者は一つの積み重なりを移動する意図で下段を操作するため、決定的な支持関係に限って上段を連動させる必要がある。一方、複数支持、張り出し、支持不可面との接触を自動的な親子関係とみなすと、利用者の意図を誤って推定する。

支持不可に変更した直後の正面積接触は、接触なしやZ不一致と同じ `support-contact-invalid` では原因が分かりにくい。段積み設定を修正すべき状態を専用理由として示す。

## Decision

- 移動開始前の正規Projectで、支持可の単一積荷上面が対象底面をX/Y両軸で完全包含し、Zが一致する `single` 支持だけを親子関係とする。
- 選択積荷を根として親子関係を再帰的にたどり、すべての子孫を根と同じX/Y/Z差分で平行移動する。子孫の向きと相対位置は変えない。
- 3DのX/Y dragと座標dialogの平行移動へ同じ規則を適用する。回転、積荷定義編集、複数支持、張り出し、支持可否混在、不適合接触には連動を適用しない。
- 一つの連動移動はProject全体を一回だけ検証・commitし、一回のUndo/Redoで全配置を往復する。子孫の座標が保存可能範囲外になる場合は全体を変更しない。
- 子孫がある根をdrag-outまたは配置解除で荷室外へ出す操作は拒否し、先に上の積荷を外すよう案内する。
- 3D drag previewでは連動する子孫も同じ差分で表示し、取消・pointer中断・commit失敗では全meshを開始位置へ戻す。
- 支持不可面との正面積接触だけで床より上の積荷を支えている場合は `support-permission-denied` を不適合理由とし、関連積荷の段積み設定が原因であることを示す。接触なし、Z不一致、辺・点接触は従来どおり `support-contact-invalid` とする。

## Impact

- Users: 決定的な積み重なりを一体として移動でき、段積みNGの原因を直接理解できる。
- Data: Project、JSON、Schema `0.1.0`は変更しない。支持グループと判定理由は正規Projectから導く派生状態である。
- Compatibility: 既存保存データの移行はない。既存配置は操作または判定時に新規則を適用する。
- Tests: 直列3段、枝分かれ、上段だけの移動、複数支持・支持不可の非連動、座標範囲失敗のrollback、drag preview・取消・drop・Undo/Redo、drag-out・配置解除拒否、専用理由と表示文を検証する。

## Rollback

連動移動を単一配置更新へ戻し、`support-permission-denied` を `support-contact-invalid` へ統合する。Schemaと保存データのrollback migrationは不要である。
