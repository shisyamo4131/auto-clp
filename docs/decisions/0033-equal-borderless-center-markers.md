# 0033 同径・外枠なしの重心ドット

- Date: 2026-09-08
- Status: Accepted
- Related specification: Application Shell and Primary Workflow
- Partially supersedes: 0032のドット寸法、外枠、完全一致・近接時の見せ方
- Retains: 0032の計算、対象、4状態、再計算、保存境界、凡例の意味、非保証範囲

## Context

ADR 0032は、赤いコンテナ幾何中心を大きな外側ドット、黄色い積荷合成重心を小さな内側ドットとして表示し、白い外枠などの輪郭差で完全一致時にも両点を露出させていた。

人間による初回表示確認で、赤いドットを黄色と同じ大きさにし、両ドットから白い外枠を除く変更が要求された。同径・不透明・同中心の二点を座標変更なしで同時に露出させることはできないため、完全一致時の重なり方も明示する必要がある。

## Decision

- コンテナ幾何中心の赤いドットと積荷合成重心の黄色いドットを、どちらも10 CSS pxの円とする。
- viewport上の両ドットと凡例の両swatchから、白いborder、outlineおよび白い外枠として見えるshadowを除く。
- 黄色いドットを赤いドットより前面へ重ねる。
- 二点の画面投影中心が完全一致する場合は座標をずらさず、黄色いドットが赤いドットを完全に覆うことを許容する。赤を露出させる外周、切欠き、分割、offsetは追加しない。
- 近接して表示領域が重なる場合も各投影中心を維持し、重なった部分では黄色を前面にする。
- 完全一致時に赤が見えないことを、赤点の欠落、異常、合否または警告とは解釈しない。常設凡例と読み上げ用名称は両中心の役割を引き続き示す。
- 点の正規3D位置、画面投影、固定画面サイズ、非操作性、画面外status、4状態、再計算、保存除外、計算式、安全上の非保証範囲はADR 0032から変更しない。

## Consequences

- 完全一致は黄色い一つの円として見え、赤はその背後に存在する。
- 赤・黄の寸法差や白い輪郭には依存しない簡素な表示になる。
- 完全一致だけを見て二点の存在を同時に視覚確認することはできないため、凡例と読み上げ用名称を維持する。
- CLP Schema `0.1.0`、保存データ、計算結果、scene座標、利用事項内容版`1.2.0`、進捗配点は変更しない。

## Verification

- UI/browser: 赤・黄markerと凡例swatchが各10 CSS pxで、白いborder、outline、外枠shadowを持たない。
- UI/browser: 完全一致時に二点の中心と寸法が一致し、黄色が赤より上にあり、赤のglowも露出しない。
- UI/browser: 近接・離隔・画面外、DPR 1/2、camera操作、305 / 320 / 375 px、pointer・focus・cargo操作非干渉の既存回帰を維持する。
- Regression: typecheck、lint、単体、全browser、build、データ契約、文書索引・ロードマップ検査を実行する。
- Human: 実ブラウザで同径・外枠なしの見た目、近接時の重なり、凡例理解を確認する。
