# 0043 分離可能な2面スナップとカーソル配置面選択

- Date: 2026-09-17
- Status: Accepted
- Related specification: Placement and Validation
- Refines: ADR 0019、0041、0042

## Context

ADR 0042のX/Y fitは50 mm以内の候補から1面だけを選び、境界を1 mm越えると直ちに解除していた。このためコンテナ角や2つの積荷へ同時に面を合わせられず、吸着後も小さいpointer移動で外れやすかった。また支持面の選択はX/Y正面積が1 mm²でもあれば側面fitより先に上面へZ snapするため、床で隣接させる操作が意図せず段積みへ変わった。

固定した侵入距離だけで床配置と段積みの意思を推測すると、積荷寸法に対する割合が変わり、上段からの移動も床からの接近も同じ規則で処理してしまう。X/Y整列とZ配置面選択を分離し、将来整列方法を全面的に変更する場合はスナップだけを撤去できる境界が必要である。

## Decision

- fine-pointer dragのX/Y整列は、コンテナ内壁または固定積荷側面からX軸最大1面、Y軸最大1面を選び、最大2面へ同時にfitできる。内壁＋内壁、内壁＋積荷、異なる積荷＋積荷を許可する。
- X/Yを順番に確定せず、なし・単一軸・二軸の候補を作り、二軸候補を優先して最終位置で移動グループ全体の立体重複と各対象面への正面積接触を再検証する。二軸が不成立なら単一軸へfallbackする。同順位は合計移動量、X軸、内壁、積荷ID・面方向の決定順で選ぶ。
- 新規吸着は従来どおり各軸50 mm以内とする。drag中に吸着した軸と対象だけを一時保持し、75 mm以内では同じ対象を候補に残す。76 mm以上離れた軸は解除する。保持はpointer up、cancel、Escape、Project更新、または切替OFFで破棄し、Project、JSON、端末保存、Undo/Redoへ含めない。
- Z配置面はX/Y整列とは別に、移動グループを除外したraycastでカーソル直下の可視面から選ぶ。最前面の上向き積荷面を指しており、支持可かつ移動積荷底面と正面積がある場合はその上面を選び、それ以外は床面を選ぶ。
- 既に支持上面からdragを開始した場合、またはdrag中に上面を取得した場合は、カーソルが外れても対象積荷との底面正面積が残る間はその上面を保持する。正面積がなくなれば床面へ戻し、完全な荷室外は常にZ=0とする。
- 床面から開始して側面へ近づける操作は、カーソルが上面を指さない限り、浅いX/Y重なりだけで段積みへ変更しない。速度、滞在時間、固定した侵入深さは段積み意思の判定に使わない。
- `adjust` buttonはX/Yの積荷側面・内壁スナップだけを制御する。床面／上面の選択、支持判定、衝突判定は基礎配置機能として維持する。
- X/Yスナップは、生のdrag座標と配置面選択の後、衝突・支持の最終検証より前に適用する独立処理とする。スナップ固有の計算、drag-session保持、表示、buttonを除去しても、生のdrag、配置面選択、支持・衝突検証、矢印調整が残る構造を維持する。

## Rationale

二軸の最終位置を一括検証すれば、各軸単独では安全でも組合せ後だけ衝突する順序依存を避けられる。取得と解除に小さい差を設けることで境界付近の揺れを抑えつつ、100 mm固定保持による大きなpointerずれを避けられる。カーソル直下の面は、積荷寸法に依存する侵入量より利用者の配置意図を説明しやすい。

## Impact

- Users: コンテナ角、内壁と積荷、2つの積荷へ2面同時に合わせられる。床で側面へ寄せる操作と、上面を指して段積みする操作を分けられる。
- Data: Project、JSON、Schema `0.1.0`を変更しない。面候補、吸着保持、カーソル配置面はsession限定の派生状態である。
- Compatibility: 既存JSON、端末保存、配置座標、Undo/Redoにmigrationはない。座標dialog、矢印調整、回転は従来どおり明示座標または既存規則を使う。
- Tests: 内壁角、内壁＋積荷、積荷＋積荷、二軸合成衝突fallback、50 / 51 mm取得、75 / 76 mm解除、OFF、床側面接近、上面取得・保持・完全離脱、移動グループ除外、荷室外Z=0を検証する。

## Rollback

X/Yの複数候補、drag-session保持、対象面表示、`adjust` buttonを撤去し、生のdrag座標を配置面選択と既存の支持・衝突検証へ直接渡す。必要なら配置面入力も既存の自動支持候補選択へ差し戻せる。Projectと保存形式を変更しないためmigrationは不要である。

## Reconsider When

camera距離に依存しないscreen-space取得・解除、利用者別閾値、touch操作、床／上面の明示モード、非直方体、設定隙間へのfit、または上面端での部分支持を主操作にする必要が生じた場合。
