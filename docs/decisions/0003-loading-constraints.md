# 0003 初期積載制約の範囲

- Date: 2026-08-27
- Status: Accepted
- Related specification: Placement and Validation
- Supersedes: None

## Context

3D表示だけでは実務判断に不足し、開口部、段積み可否、重量、積荷間の必要隙間を配置と同時に評価する必要がある。一方、搬出順は当面不要とされた。

## Decision

初期制約として、積載空間境界、積荷同士の重なり、開口部通過、積荷ごとの段積み可否、積荷重量合計とコンテナ耐荷重、X・Y・Z軸別の固定隙間を扱う。搬出順、重心、軸重、荷崩れ防止、支持率、上載荷重は未決定または現在範囲外とする。

## Rationale

利用者が明示した必須条件を最初の試作に含めながら、未定義の物理安全モデルを保証として誤実装することを避ける。

## Alternatives

- 容積だけの判定: 実務上重要な開口部、重量、段積みを見落とすため不採用。
- 完全な力学モデル: 必要データと受入基準が未確定なため初期採用しない。

## Impact

- Users: 積荷ごとに重量と段積み可否、案件ごとに軸別隙間を入力する。
- Data: コンテナは耐荷重と開口部情報を保持する。
- Implementation: 各制約は独立した理由コードを返す。
- Tests: 各制約の合格、不合格、境界、複合失敗を検証する。
- Operations: 判定は計画支援であり、実積載の安全保証ではないと表示する。

## Migration

未決定制約を後から追加できるよう、JSONスキーマをバージョン管理する。

## Reconsider When

初期利用者が重心、軸重、支持率、上載荷重または搬出順を必須と評価した場合。
