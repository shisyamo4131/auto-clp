# 0002 直方体を基本とする積荷モデル

- Date: 2026-08-27
- Status: Accepted
- Related specification: Cargo; Placement and Validation
- Supersedes: None

## Context

精密機器の形状は多様だが、任意形状の厳密な3Dネスティングは入力・計算・検証を著しく複雑にする。実務では凹凸を組み合わせて一体として扱える場合がある。

## Decision

積荷の基本形状を直方体とし、長さ・幅・高さの軸を入れ替える回転を許可する。凹凸を組み合わせる場合は、利用者が組み合わせ後の一つの直方体として登録する。積荷ごとの回転制限機能は未決定とする。

## Rationale

直方体は入力しやすく、衝突、境界、支持、開口部、自動配置を一貫したデータモデルで検証できる。複雑形状を利用者判断でまとめることで、初期実装の複雑性を抑える。

## Alternatives

- 任意の3Dメッシュ: 入力方法、衝突検出、最適化が初期目的に対して過大。
- 2D平面のみ: 高さ方向の段積みを評価できないため不採用。

## Impact

- Users: 複雑形状は安全側の外接直方体または組み合わせ後寸法として入力する。
- Data: 寸法、位置、回転を軸整列直方体として表現する。
- Implementation: 6方向の軸入れ替えを基本候補とする。
- Tests: 各向き、接触、隙間、はみ出しの境界値が必要。
- Operations: 近似モデルであることを利用者に表示する。

## Migration

None。将来形状種別を追加する場合も、既存直方体データを有効に保つ。

## Reconsider When

実務評価で、直方体近似による容積損失または誤判定が主要な障害になった場合。
