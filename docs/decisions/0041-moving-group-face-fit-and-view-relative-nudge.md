# 0041 移動グループ判定・側面fit・視点基準矢印調整

- Date: 2026-09-16
- Status: Accepted
- Related specification: Placement and Validation, Operation History
- Refines: ADR 0018、0019、0020、0035、0039

## Context

ADR 0035で単一支持子孫は下段と同じ差分をpreview・保存するようになったが、ADR 0019の支持面snapは選択した根だけを候補から除外していた。そのため短距離dragでは、移動前の上段積荷が固定された支持候補または衝突候補として残り、下段が上段の旧位置へsnapして空中配置になり得た。

既存の支持面内clampだけでは、床面または同じ上面にある隣接積荷へ側面を正確に合わせにくい。一方、常時fitすると意図的な小さい間隔を作りにくいため、視点に沿った整数mmの微調整が必要になった。

## Decision

- drag開始時の正規Projectから、根と再帰的な単一支持子孫を一つの移動グループとして先に確定する。床・支持面snap、側面fit、立体重複の候補から移動グループ全体の移動前配置を除外する。
- 床または支持面Zを解決した後、同じ最小Zにある固定積荷と直交軸で正面積が重なる側面までの距離が20 mm以内なら、最小移動量のX/Y側面へ隙間0 mmでfitする。閾値は単一定数とする。
- 同距離ではX軸、積荷ID、符号の順で決定する。fit後に根または子孫が移動グループ外の積荷と正体積で重なる候補は採用しない。移動グループ内部の既存相対接触は衝突としない。
- 配置済み積荷を選択し3D canvasへfocusした状態の修飾キーなし矢印キーだけを、現在cameraで画面水平へ最も強く投影されるコンテナ軸と残る軸へ割り当てる。各stepはXまたはYの一軸を正確に1 mm変更し、Zと向きは維持する。
- 矢印調整はコンテナ境界、支持面端、完全な支持喪失を許容し、不適合または未確認の修正途中配置として保存できる。移動グループ外の積荷との正体積重複だけはそのstepを拒否し、面接触は許容する。
- 根に単一支持子孫がある場合は同じ差分で連動させる。通常押下または同一keyの長押しrepeatをkey releaseまでpreviewし、一回の `placement.keyboard-nudge` commitおよびUndo/Redo履歴へまとめる。Escape、window blur、描画更新、保存失敗、staleではpreview全体を開始位置へ戻す。
- 入力欄、選択欄、dialog、3D外にfocusがある時は矢印キーを奪わない。camera方向、zoom、Project Schema、保存形式は変更しない。

## Rationale

移動対象を先に確定すれば、描画・snap・衝突・保存が同じグループ境界を共有し、旧位置を固定物として扱う矛盾を除ける。20 mmの側面fitは一般的なpointer操作の誤差を吸収し、1 mmの明示調整はfit後の意図的な間隔と修正途中配置を決定的に作れる。camera投影から軸を選べば、正規座標を一軸ずつ保ちながら利用者の画面上の方向感覚と一致させられる。

## Impact

- Users: 床・上面の隣接積荷へ側面を合わせ、矢印キーで視点基準に1 mmずつ離す・寄せる操作ができる。積層の短距離dragで旧上段を支持物と誤認しない。
- Data: Project、JSON、Schema `0.1.0`は変更しない。fit候補、移動グループ、keyboard preview、camera軸対応は派生状態である。
- Compatibility: 既存JSON・端末保存は移行なしで読み書きできる。既存の座標dialog、回転、drag-out、物理判定は維持する。
- Tests: 移動グループ除外、20 / 21 mm境界、床・上面fit、同値順、グループ衝突、面接触、支持喪失・境界外、視点軸対応、長押し一回履歴、Undo/Redo、Escape・blur・busy・focus保護を検証する。

## Rollback

側面fitと矢印キー入口を撤去し、支持面snapをADR 0019のZ snap・単一面clampへ戻す。移動グループ全体を旧位置候補から除外するバグ修正はADR 0035との整合に必要なため維持する。Schemaと保存データのrollback migrationは不要である。

## Reconsider When

利用者別のfit閾値、設定隙間へ直接fitする操作、斜め・連続座標移動、Z方向keyboard操作、touch gesture、または支持喪失を禁止する安全モードが必要になった場合。
