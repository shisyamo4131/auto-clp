# 0023 WebGL 2必須運用と読み取り専用JSON救出

- Date: 2026-08-30
- Status: Accepted
- Related specification: Environment and Boundaries; Persistence; Error Handling
- Supersedes: None
- Refines: 0001, 0013

## Context

従来はWebGL 2を利用できない場合も、フォーム編集、物理判定、履歴、保存、JSON入出力、自動提案を利用できるfallbackを提供していた。しかしAuto CLPの主作業は3Dで積荷と荷室の関係を視覚的に把握しながら操作することであり、3D表示なしに数値と一覧だけで案件を変更できる状態は、利用者が結果を十分に把握できないまま操作を確定する危険がある。人間評価者はこのfallback前提を不適切と判断し、Auto CLP自体を利用不能にする方針を承認した。一方、描画障害が作業中に起きた場合にメモリ内案件や既存端末保存を救出できないとデータ喪失につながる。

## Decision

- WebGL 2能力確認と初回Three.js描画成功を、案件操作を開始するための必須ゲートとする。確認中の作業画面は操作不能とする。
- WebGL 2非対応、初期描画失敗、描画例外またはWebGLコンテキスト喪失では、案件編集、3D配置、物理判定、自動提案、履歴、端末保存・読込・削除、JSON読込を全面停止し、通常作業面を表示しない。
- 障害時も現在のメモリ内Projectは破棄しない。例外として、現在案件を `auto-clp-project-0.1.0.json`、IndexedDBの `current-project` を `auto-clp-device-rescue-0.1.0.json` へ明示的にダウンロードする読み取り専用救出だけを許可する。
- 端末保存の救出はreadonly transactionで保存文字列を取得し、現在案件へ読み込まずに複製する。救出画面はimport、編集、削除、端末保存の作成・上書きを提供しない。
- 救出画面は人向けに「作業データをファイルへ退避」と表現し、現在メモリ内の作業内容と最後に端末へ保存した内容の違い、各固定出力名、復旧後のJSON読込、端末保存を上書きしないことを操作前から示す。操作後はdownload完了を保証せず、開始したこと、対象ファイル名、browserのdownload一覧またはfolderを確認する次行動を持続表示する。
- 復旧はWebGL 2を利用できるブラウザ・GPU設定へ戻してページを再読み込みし、能力確認と初回描画を再度通過する方法だけとする。描画障害後に同一画面で操作可能へ復帰しない。

## Rationale

3D表示を任意の補助表示ではなく操作成立条件にすると、利用者が空間関係を確認できない状態で配置や判定を変更する経路をなくせる。障害時の例外を読み取り専用ダウンロードへ限定すれば、操作安全性を保ちながら、未保存のメモリ内案件と既存端末保存のデータ喪失リスクを下げられる。SchemaやProject意味を変更せず、外部通信や新しい権限も必要としない。

## Alternatives

- 従来どおり非対応時もフォーム・判定・保存を利用可能にする案は、視覚確認不能な操作を許すため採用しない。
- 物理判定だけを利用可能にする案は、表示結果と3D配置の対応を利用者が確認できないため採用しない。
- 障害時に一切の操作をなくす案は、作業中データを救出できないため採用しない。
- 自動復旧またはWebGL 1 / 2D表示へ降格する案は、同等の空間認識と検証済み動作を保証できず、現在範囲を超えるため採用しない。

## Impact

- Users: WebGL 2を利用できない環境ではAuto CLPを使用できない。明示的な阻止表示、GPU・ブラウザ確認と再読込案内、読み取り専用JSON救出だけを利用できる。
- Data: Project Schema `0.1.0`、JSONの形・意味、IndexedDBのDB版と保存キーは変更しない。救出は保存内容を変更しない。
- Implementation: Appの能力状態を操作ゲートに昇格し、通常作業面とfallback操作を非対応・障害状態から外す。現在案件と端末保存に別の固定名download経路を設ける。
- Compatibility: WebGL非対応環境で使えた従来のフォーム、判定、履歴、保存、自動提案を削除するため、仕様1.0.0の非互換変更である。
- Tests: 能力確認中の操作不能、非対応・初期描画失敗・context lossの全面停止、通常環境、現在作業データ退避、readonly端末保存退避、固定名、説明と持続する開始結果、退避失敗、305 pxでのoverflow、通常の保存・JSON・履歴・判定・自動提案回帰を検証する。

## Compatibility and Migration

既存JSONと端末保存はSchema `0.1.0`のまま互換である。WebGL 2対応環境で従来どおり読み込める。非対応環境で必要な場合は固定名JSONへ救出し、対応環境で再読込する。アプリ起動時の自動読込や保存データ自動移行は行わない。

## Rollback

能力ゲート、救出UI、専用固定名、関連試験と文書を同じ変更として戻せる。rollbackはIndexedDBの保存コピーを削除・変更しない。ただしfallback操作を復活させるには、視覚確認なしの操作を再び許す明示的な仕様承認が必要である。

## Reconsider When

WebGLなしでも同等の空間理解と操作確認を提供できる検証済み2D/代替描画、GPU復旧を伴う安全な同一画面復帰、または別製品としての非3D閲覧専用モードが承認された場合。
