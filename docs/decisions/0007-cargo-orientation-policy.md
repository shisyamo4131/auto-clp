# 0007 積荷別の許可回転

- Date: 2026-08-27
- Status: Superseded
- Superseded by: ADR 0022
- Related specification: Cargo; Placement and Validation
- Supersedes: None
- Refines: 0002

## Context

直方体には最大6種類の寸法軸の割当があるが、精密機器を横倒しできるとは限らない。全向きを暗黙に許可すると安全側でなく、入力向きだけに固定すると手動配置の有用性が低い。

## Decision

- 各積荷は、元の長さ・幅・高さを世界X・Y・Zへ割り当てる6種類の直交向きから、許可向きの集合を持つ。
- JSONでは向きを列挙値として保存し、立方体など寸法が同じ場合も識別子は安定させる。描画・探索では同一寸法結果を重複候補から除外できる。
- 新規積荷の既定は、高さ軸をZに保つ2種類の水平向きだけを許可する。横倒しまたは天地反転を含む残り4種類は利用者が明示的に許可する。
- 許可集合は空にできない。手動回転、自動提案、開口部判定は同じ許可集合だけを使用する。
- 直方体モデルは前後・天地の意味や機器内部の方向性を表現しないため、方向ラベルが必要な案件は未確認として扱う。

## Rationale

既定で高さを維持することで不用意な横倒しを避けつつ、床面上の90度回転は利用できる。単一の許可集合を全機能で共有すると、手動操作と自動判定の矛盾を防げる。

## Impact

- Users: 横倒し可能な積荷だけ追加向きを有効にする。
- Data: 各積荷に非空の `allowedOrientations` を保存し、配置はそのうち一つを参照する。
- Implementation: 回転UIは許可向きだけを循環し、不許可向きの読込データを拒否する。
- Tests: 既定2向き、全6向き、空集合拒否、不許可配置拒否、同寸法向きの決定性を検証する。

## Compatibility and Migration

アプリと永続データは未実装のため既存データ移行はない。将来、前後や天地の方向性を追加する場合も既存の許可集合を保持し、追加属性を既定なしで導入する。

## Rollback

実装前は本ADRと対応仕様を戻せる。実装後に既定値を変えても既存積荷の明示的な許可集合は変更しない。

## Reconsider When

初期利用者が方向ラベル、任意角度、傾斜姿勢、または積荷カテゴリ別の既定向きを必要とした場合。
