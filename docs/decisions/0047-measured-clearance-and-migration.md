# ADR 0047: 実間隔・配置図と明示的な旧データ移行

- Status: Accepted
- Date: 2026-11-04
- Scope: Schema 0.3.0の通常画面と帳票
- Supersedes: ADR 0011の通常画面の閾値判定、ADR 0044の積込順依存、ADR 0046の通常読込・保存先（旧形式の検証契約は維持）

画面の固定欄・詳細・表示切替は[ADR 0048](0048-top-view-clearance.md)の2D常時表示・3D非表示へ更新。以下の測定・保存・帳票契約は維持する。

## 決定と理由

利用者が必要とするのは現在の間隔の確認であり、CLP共通閾値による合否ではない。共通の純粋関数で、X/Y各方向の対向面間距離を計算する。面の直交方向と高さが正に重なる相手のみ対象とし、壁・段差面を含める。各方向の最寄りを代表表示し、詳細で全対向候補を確認する。天井は対象外。衝突・床・支持・重量判定は維持する。

画面は正規値と実際に描く移動プレビューから測定する。連動荷も同じ移動量を反映する。表示の切替や計算だけでは保存状態を変更しない。

配置図は順序計算を経由せず固定cargoNoを使う。上面図専用A4横ページの図内へ実間隔を掲載し、別の間隔一覧ページへ逃がさない。名称・重量一覧は別ページを維持する。図に収容できない場合は失敗を通知する。可読性の最終判断は生成物によるユーザー確認を残す。

## 互換性・移行・復旧

0.3.0でclearancesMmを廃止する。旧Schema検証を通過した旧JSONだけを、変換後検証とWorker事前判定の成功後に確認する。原本保存・変換・取消を提供する。0.1.0のNoは配列順、0.2.0のNoとnextCargoNoは維持。形状・配置・重量・支持設定は保持する。読み込みで自動保存しない。

端末はcurrent-project-v3に保存。v3→v2→旧枠の順で、不在(undefined)だけをfallback条件にする。nullと破損で停止する。原本と旧枠を残す。旧版への復旧は旧原本を使用し、新版で追加した編集は旧原本に含まれない。縮退書出しはしない。

## 検証と境界

[実装計画C0〜C5](../designs/recessed-floor-openings-clearance.md#クリアランス機能の実装計画)と[受入](../acceptance.md)に従い、保存互換・計算境界・ドラッグ・PDF・回帰を確認する。外部公開、複数開口、支持設定の既定値変更は本決定に含まない。
