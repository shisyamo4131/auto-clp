# 0014 床突き抜けの専用診断

- Date: 2026-08-28
- Status: Accepted
- Related specification: Placement and Validation; Error Handling
- Supersedes: None
- Refines: 0012

## Context

ADR 0012はコンテナ境界外を最優先の座標理由とするが、床下と壁・天井の境界外を同じ `outside-container` として表示していた。利用者が最初にZを直すべき床突き抜けを、一般的なはみ出しと区別できない。

## Decision

- 向き適用後の積荷境界の最小Zが0 mm未満なら、安定した専用理由 `floor-penetration` をその積荷の先頭の不適合理由として返す。
- 最小Zが0 mm以上で別の面を越える場合は、従来の `outside-container` を使う。床と他面を同時に越える場合は `floor-penetration` を座標理由として返し、同じ積荷へ `outside-container` を重複させない。
- 床突き抜けはADR 0012の境界違反と同じカスケード抑制を使い、その配置自身のコンテナ隙間・支持不足と、境界違反だけから生じるpair理由を重ねない。
- 開口寸法、総耐荷重、搬入経路、構造・安定性など座標境界と独立して成立する理由は保持する。
- 表示は床を突き抜けていることと、Zを0以上へ直す必要を明記し、案件名、積荷名、座標値を理由本文へ反射しない。対象欄は既存の安全な表示経路を使う。

## Rationale

「床またはコンテナ境界」という共通文では、床下の積荷に対する最初の修正が伝わりにくい。専用理由に分けると、他の境界規則を緩めず、利用者がZ座標を先に直せる。

## Impact

- Users: 床突き抜けを壁・天井のはみ出しと区別し、修正順を理解できる。
- Data: 案件JSON、Schema `0.1.0`、保存値を変更しない。診断は再計算される派生値である。
- Implementation: 物理判定の理由union、決定的順序、表示文言を拡張する。Workerの転送形式は既存reason構造を維持する。
- Tests: Z=-1、Z=0、他面境界、同時境界、独立した開口・耐荷重、カスケード抑制、表示文言、Worker経由UIを検証する。

## Compatibility and Migration

正規案件データに変更はなく移行不要である。同じ床下案件の派生理由codeと表示が、一般境界外から専用床突き抜けへ改善される。

## Rollback

仕様、ADR、実装、テスト、受入契約を同じコミットで戻す。公開後に理由codeを統合または変更する場合は後継ADRで明示する。

## Reconsider When

床厚、斜面、複数床面、車輪止め、床下空間など、`z = 0` の単一平面では表せないモデルを導入するとき。
