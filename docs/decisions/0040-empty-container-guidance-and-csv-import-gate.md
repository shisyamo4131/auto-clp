# 0040 コンテナ未登録時の案内とCSVインポート制限

- Status: Accepted
- Date: 2026-09-16
- Related specification: `../specification.md` 1.10.2
- Refines: 0025、0030、0034

## Context

積荷だけを含むJSONを読み込むと、積荷は正常に復元されても、荷室外積荷の3D位置を決める基準となるコンテナがないためviewportには表示されない。現行画面はコンテナ0件・積荷件数を読み上げるだけで、利用者が次に行うコンテナ登録へ直接進めなかった。また、CSV一括登録はコンテナなしでも開始でき、同じ分かりにくい状態を新たに作れた。

## Decision

- コンテナ0件では3D viewport中央へDOM overlayで「コンテナを登録してください」と表示する。
- overlay内の「登録」buttonは既存のコンテナ追加dialogを開く。別のCLP操作または保存処理中はbuttonを無効にする。
- コンテナ0件ではDrawerの「テンプレートインポート」を無効にし、「テンプレートを読み込む前にコンテナを登録してください。」と理由を表示する。
- 「テンプレートダウンロード」と「JSONから読込」はコンテナ件数に依存させない。積荷だけを含む既存JSONも引き続き読み込み、コンテナ登録後に3D表示できる。

## Consequences

- JSON読込成功と3D表示不可を区別でき、メイン画面から次の操作へ進める。
- CSV一括登録はコンテナが1件以上ある場合だけ開始できる。CSV形式、積荷置換、配置解除、Undo/Redoの契約は変更しない。
- Schema `0.1.0`、JSON、CSV、IndexedDB、既存Projectの意味は変更せず、データ移行は不要である。

## Verification

- browser試験で、コンテナ0件の中央案内、「登録」からの既存dialog表示、busy時の無効化、狭幅を確認する。
- browser試験で、コンテナ0件ではテンプレートインポートだけが無効になり、理由を表示し、テンプレートダウンロードとJSON読込は利用可能であることを確認する。
- コンテナ登録後のCSV置換、確認、Undo/Redo、3D表示に関する既存回帰を維持する。

## Rollback

中央overlayとCSVインポートのコンテナ件数条件を撤去する。保存形式とデータを変更しないため、データrollbackまたはmigrationは不要である。
