# ADR 0048: 2D上面操作と積荷周囲の実間隔

- Status: Accepted
- Date: 2026-11-05
- Scope: 画面内の2D／3D切替と実間隔配置
- Refines: ADR 0047（測定計算・保存契約は維持）

## 決定と理由

ユーザーが推奨案をすべて採用した。上面の正投影を既存viewerに追加し、配置データと実間隔計算を共用する。対象荷の周囲に最大4方向の距離を表示し、相手名は添えない。平面の配置と隙間を直接対応させるため、2Dは固定欄を置き換え、狭い隙間には引出線を付ける。選択荷の寸法はNoの下へまとめて間隔線と分離する。

Z手操作は提供せず、床面の積荷を通常床・段落ち床へ自動追従させる。段差跨ぎの確定拒否を維持。他荷への乗り上げを避け、段積み・浮いた荷と上段を支える荷の編集は3Dへ案内する。座標入力も高さを含むため3Dで行う。3Dカメラを別に保持し、切替で選択・配置・履歴を変えない。

## 互換性・復旧・検証

Schema 0.3.0、保存枠、旧版移行、PDF専用上面図は変更しない。2Dからの現在視点画像は正投影を保持する。復旧時は3Dボタンから従来操作へ戻れる。実装差分を戻しても保存データの変換は不要。外部配信・依存関係・権限変更は含まない。

検証は型・lint・全単体・全browser・build・データ契約・文書検査・diff-check。個別回帰は四方向、接触、重なり、狭い間隔、移動中更新、取消、段差跨ぎ、床高さ追従、段積み制限、回転、視点切替、拡縮・panと保存非影響。操作感の最終受入は利用者確認を残す。

## 2026-11-05の試用による表示方針の更新

ユーザー指示により、2Dに切り替えれば実間隔を確認できる構成へ簡略化する。「実間隔」チェックボックスを撤去し、2Dの選択荷周囲へ常時表示する。3Dは実間隔の線・数値・詳細欄を非表示にする。3Dの寸法矢印は移動中も維持する。これがADR 0047の画面固定欄・詳細・独立した表示切替に優先する。計算規則、保存形式、PDFの間隔表示は維持。復旧は表示実装のみを戻せばよく、データ変換不要。2D／3Dの往復、移動・取消、チェックボックス不在、PDFと3D寸法表示を回帰する。

## 全積荷の常時表示への更新

ユーザー指示により、選択荷だけの表示を、表示中コンテナの全配置積荷へ拡張する。各荷の四方向の代表測定を維持し、同じ積荷間の同一線分だけを一つへまとめる。壁・段差面の間隔は各荷ごとに残す。移動中は一つのプレビュー配置を全測定へ反映し、周辺荷の値も更新する。計算結果をカメラ操作・選択変更だけでは作り直さず、画面への投影を更新する。数値の背景を全寸法線より後に描画して線が文字を横切ることを避ける。数値を黙って間引かず、密集時は拡大・平行移動で確認する。3D非表示、保存形式、PDFは変更しない。

復旧は選択荷表示へコードを戻せばよく保存データの変換は不要。未選択・選択解除、全方向の所有、相互測定の重複整理、移動に伴う隣接荷の更新と取消、コンテナ切替、3D非表示を回帰する。
